# Лисёнок и звёзды

Приключение с чтением и счётом для детей 5–9 лет. Ночью с неба упали звёзды, и лисёнок
возвращает их домой: на каждой полянке лесной житель просит помочь — прочитать, собрать слово,
посчитать или решить пример. Работает в браузере телефона и без интернета (после первого запуска).

## Что внутри

- **Карта миров:** Лес (открыт), Море, Горы, Город, Космос (скоро).
- **Лес — 9 остановок**, у каждой свой житель и навык:
  ёжик — буквы и звуки, белка — счёт, зайчик — собрать слово, сова — прочитать слово,
  медвежонок — сложение, бобр — слоги, барсук — вычитание, мышка — больше/меньше,
  лягушонок — чтение предложений.
- **Три уровня:** 5–6 лет (буквы, звуки, счёт до 10), 6–7 лет (слоги, короткие слова, ±20),
  8–9 лет (предложения, задачи до 100). Уровень подстраивается сам: две остановки без ошибок —
  сложнее, две трудные подряд — проще.
- **Голос Ксении (Silero)** озвучивает каждое задание, хвалит, подсказывает после второй ошибки,
  после третьей показывает ответ. Можно выбрать имя ребёнка.
- **Награды:** звёзды на тропинке, подарок от каждого жителя в альбоме сокровищ, праздник за весь лес.
- **Для взрослых** (удерживать ⚙ 2,5 с): имя, уровень и автоподстройка, успехи по навыкам и трудные
  навыки, лимит времени в день, громкость голоса/звуков/музыки, сброс, статус игры без интернета.

## Запуск

```bash
npm install
npm run dev            # http://localhost:8080
npm run build          # итоговая сборка в dist/ (с service worker для игры без интернета)
npm run preview        # http://localhost:8081 — итоговая сборка
```

## Проверка

```bash
npm run lint && npm run typecheck && npm test   # линтер, типы, генераторы заданий
npm run dev &                                    # игра на http://127.0.0.1:8080/
npx playwright install chromium                  # один раз
npm run test:e2e                                 # проходит весь лес на трёх уровнях в браузере телефона

# игра без интернета (итоговая сборка):
npm run build && (npm run preview &)
OFFLINE=1 BASE_URL=http://127.0.0.1:8081/ npm run test:e2e
```

## Публикация

Игра — статичный сайт (`dist/`). Опубликована на том же сервере, что и «Кто сказал?»:
https://lisenok.151.243.212.26.nip.io/ (nginx + Let's Encrypt, конфиг `deploy/nginx-lisenok.conf`).
Обновить: `deploy/update.sh` (нужен SSH к серверу). Для Vercel подходит `vercel.json`.

## Как добавить

- **Слово с картинкой:** строка в `src/content/words.ts` (и в `WORDS_BY_LEVEL`), картинка —
  лист в `assets/sheets` + `python3 tools/cut-sheet.py <лист>`.
- **Предложение:** `SENTENCES` в `src/content/words.ts`.
- **Остановку / мир:** `src/content/forest.ts`; генераторы заданий — `src/game/tasks.ts`.
- **Озвучка** любых новых строк: `npm run voice:list && python3 tools/make-voice.py <v5_ru.pt> only-missing`
  (модель: https://models.silero.ai/models/tts/ru/v5_ru.pt).
- **Звуки и музыка:** `python3 tools/make-sfx.py`.
- После замены файлов в `public/` ничего делать не нужно: `npm run build` сам пересчитывает метки
  версий, и телефоны скачают новое.

Источники звуков, голоса и музыки и их лицензии — в `assets/SOUND-CREDITS.md`.
