# Лисёнок и звёзды

Приключение с чтением и счётом для детей 5–9 лет. Ночью с неба упали звёзды, и лисёнок
возвращает их домой: на каждой полянке лесной житель просит помочь — прочитать, собрать слово,
посчитать или решить пример. Работает в браузере телефона и без интернета (после первого запуска).

## Что внутри

- **Карта миров:** Лес (открыт), Море, Горы, Город, Космос (скоро).
- **Лес — 9 остановок**, у каждой свой житель и навык:
  ёжик — буквы и звуки, белка — счёт, зайчик — собрать слово, сова — прочитать слово,
  медвежонок — сложение, бобр — слоги, барсук — вычитание, мышка — больше/меньше,
  лягушонок — чтение предложений.
- **Три уровня:** 5–6 лет (буквы, звуки, счёт до 10), 6–7 лет (слоги, короткие слова, ±20),
  8–9 лет (предложения, задачи до 100). Уровень подстраивается сам: две остановки без ошибок —
  сложнее, две трудные подряд — проще.
- **244 слова с картинками и голосом** (животные, еда, дом, школа, транспорт, одежда, природа…):
  3 буквы — первый уровень, 4–5 — второй, 6 и больше — третий. Похожие картинки (утка/гусь,
  ручка/карандаш…) никогда не стоят рядом как неправильный ответ.
- **81 предложение** (короткие «Это кот.» — второй уровень, с вопросом — третий) и **24 задачи-истории**
  на сложение и вычитание с картинками («На ветке сидели воробьи. Прилетели ещё…»).
- **Голос Ксении (Silero)** озвучивает каждое задание, хвалит, подсказывает после второй ошибки,
  после третьей показывает ответ. Можно выбрать имя ребёнка.
- **Разговоры с жителями:** перед заданиями житель и лисёнок беседуют — у каждого жителя свой голос,
  позы меняются по ходу разговора (просит о помощи → радуется). Тап по облачку — следующая реплика.
- **Награды:** звёзды на тропинке, подарок от каждого жителя в альбоме сокровищ, праздник за весь лес.
- **Лесная полянка** (открывается, когда лес пройден): бесконечная игра по 5 заданий — сначала навыки,
  где ребёнок чаще ошибается, и слова, на которых он спотыкался, потом смешанное повторение;
  после каждых 5 заданий — находка (12 штук, потом по кругу), находки видны в альбоме.
- **Музыка:** своя для карты, заданий и наград, под ней — звуки леса (ручей, птицы, ветер);
  громкость каждого слоя — в уголке родителей.
- **Для взрослых** (удерживать ⚙ 2,5 с): имя, уровень и автоподстройка, успехи по навыкам и трудные
  навыки, лимит времени в день, громкость голоса, звуков, музыки и звуков леса, сброс, статус игры без интернета.

## Запуск

```bash
npm install
npm run dev            # http://localhost:8080
npm run build          # итоговая сборка в dist/ (с service worker для игры без интернета)
npm run preview        # http://localhost:8081 — итоговая сборка
```

## Проверка

```bash
npm run lint && npm run typecheck && npm test   # линтер, типы, генераторы заданий
npm run dev &                                    # игра на http://127.0.0.1:8080/
npx playwright install chromium                  # один раз
npm run test:e2e                                 # проходит весь лес на трёх уровнях в браузере телефона

# игра без интернета (итоговая сборка):
npm run build && (npm run preview &)
OFFLINE=1 BASE_URL=http://127.0.0.1:8081/ npm run test:e2e

# те же тесты в WebKit (движок Safari):
npx playwright install webkit                    # + системные библиотеки: npx playwright install-deps webkit
PW_BROWSER=webkit BASE_URL=http://127.0.0.1:8081/ npm run test:e2e
```

Без интернета: service worker сначала кэширует оболочку (страница, код, шрифты — секунды), затем
докачивает картинки и звуки выбранного формата (AVIF/Opus или WebP/MP3); прерванная докачка
продолжается при следующем запуске, а после обновления неизменённые файлы берутся из старого кэша.

## Публикация

Игра — статичный сайт (`dist/`). Опубликована на том же сервере, что и «Кто сказал?»:
https://lisenok.151.243.212.26.nip.io/ (nginx + Let's Encrypt, конфиг `deploy/nginx-lisenok.conf`).
Обновить: `deploy/update.sh` (нужен SSH к серверу). Для Vercel подходит `vercel.json`.

## Установка, формат и скорость

- **PWA:** манифест + service worker; игра ставится на главный экран и целиком работает без сети.
- **Картинки AVIF, звук Opus:** сборка (`tools/encode-media.py`, нужны Pillow с AVIF и ffmpeg с libopus)
  кладёт в `dist/` рядом с WebP/MP3 версии AVIF/Opus (Ogg). Браузер выбирает формат при запуске,
  старые — получают WebP/MP3; service worker кэширует только выбранные файлы.
- **Адаптация по словам:** слово, на котором ребёнок ошибся или попросил подсказку, чаще попадается
  в заданиях, пока не получится дважды подряд. Подробности — в уголке родителей, «Успехи».

## Как добавить

- **Слово с картинкой:** строка в `src/content/words.ts` (уровень считается по длине слова; ударение
  в `say`: `кор+ова`), картинка — лист 3×3 в `assets/sheets`, имена в `assets/word-sheets.json`,
  затем `python3 tools/cut-sheet.py <лист>`.
- **Предложение / задача-история:** `SENTENCES` / `STORIES` в `src/content/words.ts`.
- **Ударения во фразах:** словарь `src/content/stress.ts` (`здорово → зд+орово`); на экране плюсов нет.
- **Остановку / мир:** `src/content/forest.ts`; генераторы заданий — `src/game/tasks.ts`.
- **Озвучка** любых новых строк: `npm run voice:list && python3 tools/make-voice.py <v5_ru.pt> only-missing`
  (модель: https://models.silero.ai/models/tts/ru/v5_ru.pt).
- **Звуки:** `python3 tools/make-sfx.py`; **музыка и звуки леса:** `python3 tools/make-music.py` (исходники — в `assets/SOUND-CREDITS.md`).
- После замены файлов в `public/` ничего делать не нужно: `npm run build` сам пересчитывает метки
  версий, и телефоны скачают новое.

Источники звуков, голоса и музыки и их лицензии — в `assets/SOUND-CREDITS.md`.
